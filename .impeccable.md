## Design Context

### Users
- **Primary audience**: Seventh-day Adventist youth and young adults (ages 13-30)
- **Context**: Church youth groups, Pathfinder/AY events, family game nights, college socials, camp meetings
- **Mixed ages**: Must be accessible to teens through adults; no complex UI patterns that exclude less tech-savvy players
- **Device context**: Players join on their own phones/tablets during group gatherings. Mobile-first is non-negotiable.
- **Job to be done**: Have fun together while learning about global missions, unreached peoples, and the urgency of the gospel before Jesus' return

### Brand Personality
**Bold. Spiritual. Epic.**

- The game should feel like stepping into a cinematic spiritual narrative — not a cheap church app
- Every screen should carry weight and intentionality, like the missions themselves matter
- The tone is urgent but hopeful — "the harvest is plentiful" energy, not guilt or doom
- Humor and social fun come from the gameplay (accusations, deception, reveals), not from the UI being goofy

### Aesthetic Direction
- **Visual tone**: Cinematic and atmospheric — inspired by games like Alto's Odyssey where environments tell a story
- **Theme**: Dark mode primary. Deep navy backgrounds with warm gold and bright blue accents
- **Typography**: Serif headings (Playfair Display) for narrative weight and gravitas. Clean sans (Inter) for readability
- **Motion**: Purposeful animations that create dramatic pacing — role reveals, mission results, and phase transitions should feel like cinematic moments
- **Photography**: Real-world mission locations as hero images. These ground the game in reality and remind players these are real places with real people
- **Anti-references**: Should NOT look like a generic church app, a children's Bible game, or a cheap free-to-play mobile game. No clip art, no cartoonish elements, no overly bright/saturated colors

### Design Principles

1. **Cinematic over decorative** — Every visual element should serve the narrative. Animations create dramatic tension (role reveals, mission outcomes). Nothing is decorative for its own sake.

2. **Mobile-first, thumb-friendly** — Every interaction must work on a phone held in one hand. Buttons are large (min 44px touch targets). Critical actions are reachable without stretching. No hover-dependent UI.

3. **Clarity under pressure** — Players make decisions quickly in a social setting with noise and distraction. Status, role, and required actions must be immediately obvious. Use size, color, and position hierarchy ruthlessly.

4. **Spiritual weight without heaviness** — The missionary theme is genuine, not a veneer. EG White quotes, real mission locations, and educational content earn their place. But the UI stays inviting and fun — reverent where appropriate, playful where the game demands it.

5. **Premium feel, zero friction** — The game should feel polished enough that players are impressed it's free/indie. No loading spinners where avoidable. Smooth transitions. Consistent spacing. No rough edges.

### Color System
```
Background:    #0a0e1a  (deep navy)
Card:          #141b2d  (elevated surface)
Border:        #1e293b  (subtle separation)
Text:          #e2e8f0  (primary — light)
Muted:         #64748b  (secondary text)
Gold:          #d4a843  (brand accent — room codes, special elements)
Blue:          #3b82f6  (primary actions, interactive)
Light Blue:    #93c5fd  (secondary accent)
Success:       #22c55e  (mission success, positive states)
Danger:        #ef4444  (mission failure, Babylon, destructive)
```

### Typography
```
Headings:      Playfair Display (serif) — 400-900 weight
Body:          Inter (sans-serif) — clean, readable at small sizes
Monospace:     System mono — room codes, technical elements
```

### Spacing Scale
```
Base unit:     4px (0.25rem)
Card padding:  24px (1.5rem)
Button:        16px vertical, 32px horizontal (1rem / 2rem)
Section gaps:  16px (space-y-4)
```
